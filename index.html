Business details on receipt

Only needed for the "Bluetooth thermal print" button on receipts. Most cheap 58mm BLE printers use the default shown — if yours doesn't respond, check the model's manual for its actual service/characteristic UUID. This is a best-effort feature: Bluetooth printer protocols vary a lot between brands, and it only works in Chrome/Edge on Android or desktop (not Safari/iOS, which doesn't support Web Bluetooth at all — use the regular Print button there).
